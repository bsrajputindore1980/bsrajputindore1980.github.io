手写一个零依赖静态博客生成器

~ 2026-09-20 · #python #工具

静态博客生成器听起来像个系统工程，其实核心只有三件事：读 Markdown、套模板、写 HTML。用 Python 标准库一百多行就能跑起来。

生成器的骨架

主流程非常直白：

┌─ python ─
def build():
    posts = [parse_post(p) for p in glob("content/posts/*.md")]
    posts.sort(key=lambda p: p["date"], reverse=True)
    write_index(posts)
    write_archive(posts)
    for p in posts:
        write_post(p)
    copy_assets()

Markdown 够用就好

不需要实现完整 CommonMark，博客写作真正用到的语法一只手数得过来。这个站目前支持的语法：

语法写法用途
标题## 文字小节
代码块三个反引号包裹贴代码
列表- 项目 或 1. 项目罗列
引用> 文字摘录
行内代码反引号包裹命令、文件名
链接[文字](地址)引用外站
表格竖线分隔对比信息

front matter

每篇文章开头用一小段 YAML 风格的元信息，解析只需要 str.split(":", 1)：

┌─ python ─
meta = {}
for line in raw[3:end].strip().splitlines():
    k, v = line.split(":", 1)
    meta[k.strip()] = v.strip()

为什么要自己写

  • 没有依赖，五年后的机器上依然能构建
  • 所有 HTML 都是自己生成的，想改哪里改哪里
  • 折腾本身乐趣 —— 这大概是最重要的理由
