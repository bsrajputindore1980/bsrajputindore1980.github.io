## 🛠️ Troubleshooting

### The app won't open

1. Make sure you have the latest Windows 11 updates installed.
2. Check that your system has WebView2 Runtime installed (this is usually included with Windows 11).
3. Try running the app as administrator by right-clicking and selecting "Run as administrator."

### Files don't appear

- Click the "Refresh" button in the toolbar.
- Make sure you have deleted files in your Recycle Bin. An empty Recycle Bin will show nothing.
- Try sorting by different columns (name, date, original location) to find your files.

### Images won't preview

- Preview might not work for very large files or uncommon file formats.
- Ensure the image is not corrupted or partially overwritten.
- Try copying the image out and opening it with your default photo viewer.
